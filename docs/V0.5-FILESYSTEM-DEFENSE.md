# Cortex Security v0.5 — Filesystem Discovery and Evidence Quarantine

## Scope
v0.5 adds a read-only filesystem inventory scanner, SHA-256 hashing, limited heuristic inspection of supported text formats, suspicious extension flags, and an evidence-copy workflow. It does not claim to be a complete antivirus engine.

## Scan a small folder first
From the repository root in PowerShell:

```powershell
.\scripts\run_filesystem_scan.ps1 -Target .\scripts
```

Scan another directory:

```powershell
.\scripts\run_filesystem_scan.ps1 -Target 'R:\SomeFolder' -Report '.\reports\somefolder-scan.json'
```

Default exclusions: `.git`, `.venv`, `.venv-security`, `venv`, `__pycache__`, `reports`, `node_modules`, `quarantine`, `.cortex-quarantine`. Symlinks are not followed. Files larger than 50 MB are inventoried but not hashed or content-inspected by default.

The report contains inventory metadata, hashes, heuristic findings, read errors, and explicit limitations. Findings are triage signals only.

## Preserve a suspicious file for inspection
Only do this for a file you are authorized to handle. This creates a hash-verified copy and manifest; it does not delete, disable, or stop the original file.

```powershell
python .\scripts\quarantine_manager.py 'C:\Path\To\SuspiciousFile.bin' --quarantine-dir 'R:\CortexSecurity-Quarantine'
```

Do not open or execute suspicious evidence. Keep quarantine outside scanned directories. This evidence-copy workflow is not a substitute for Microsoft Defender quarantine and does not itself stop malicious activity.

## Use Microsoft Defender
Check Defender status:

```powershell
Get-MpComputerStatus | Select-Object AntivirusEnabled,RealTimeProtectionEnabled,AntivirusSignatureLastUpdated
```

To run a Defender custom scan on a selected folder (PowerShell may require elevation):

```powershell
Start-MpScan -ScanType CustomScan -ScanPath 'R:\SomeFolder'
```

Defender should remain the primary malware detection/remediation engine while Cortex develops its own analysis and response layers. Do not disable Defender.

## Tests
```powershell
python -m unittest discover -s tests -v
```

## Limitations and next steps
- Heuristics can produce false positives and miss unknown malware.
- File hashes identify content; they do not prove a file is malicious.
- No dynamic analysis or process termination is performed.
- The quarantine manager preserves evidence only. It does not claim to stop execution.
- Next iterations should add Defender event/result correlation, safer file-format parsing, and explicit approval gates for any containment action.
